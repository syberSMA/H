      Dokumentasi REST API

      Gunakan endpoint bawaan aplikasi ini untuk mengambil source code HTML + CSS dalam format JSON dari aplikasi lain:

      GET /api/scrape?url=https://example.com

      Contoh pemanggilan via JavaScript Fetch:

      fetch('/api/scrape?url=' + encodeURIComponent('https://example.com')) .then(res => res.json()) .then(data => { console.log(data.html); // HTML lengkap console.log(data.css); // Gabungan seluruh CSS console.log(data.singleFileHtml); // HTML + CSS All-in-One });
      Berhasil disalin ke clipboard!
